# NIN

**NIN** — это легковесная консольная утилита (CLI) на .NET 10, разработанная для автоматического сканирования локальных электронных книг и синхронизации структуры библиотек с плагином **Bookmarks** для десктоп-оболочки **Noctalia Shell**.

## 🎯 Назначение автоматизации

Вместо того чтобы вручную прописывать полную shell-команду запуска и путь для каждой новой книги в конфигурации плагина `Bookmarks`, утилита **NIN** полностью берёт эту рутину на себя. 

Она сканирует вашу директорию с книгами (включая один уровень подпапок для категоризации) и автоматически генерирует правильный JSON-файл закладок. При клике на книгу в меню Noctalia Shell, она мгновенно открывается в программе (например, читалке PDF/EPUB), указанной в глобальных настройках.

## ✨ Особенности

- **Интеграция с Noctalia Shell:** Автоматическая генерация валидных shell-команд запуска для каждой книги.
- **Строгий 1-й уровень вложенности:** Идеально мапится на интерфейс плагина (Корень -> Папки категорий -> Книги).
- **Безопасный аудит (Dry Run):** Возможность проверить изменения на диске или в базе данных без перезаписи файлов.
- **Собственный парсер:** Отказ от сторонних форматов (вроде TOML) в пользу собственного оптимизированного решения, размещенного на GitHub.
- **Высокая скорость:** Написано на .NET 10 с использованием библиотеки `System.CommandLine`, работает мгновенно.

## ⚠️ Важное примечание перед использованием

> **Обратите внимание:** На текущий момент дефолтные конфигурационные пути в коде жестко захардкожены под профиль автора. Перед полноценным запуском утилиты **обязательно перенастройте пути под своего пользователя** с помощью команды `set`.
>
> Папка конфигурации приложения в директории `~/.config/` и сам файл настроек **создаются автоматически только после того, как вы измените хотя бы один параметр** через команду `set` (в будущем это поведение может быть обновлено).

## 🏛️ Архитектура проекта

Код декомпозирован на логические блоки для простоты поддержки:
- `/CLI` — содержит декларативные классы команд (`RootCommand`, `SetCommand`, `LibCommand`, `CheckCommand`).
- `/Core` — основная бизнес-логика (`Bookmarks.cs` для синхронизации, `DiskScanner.cs` для чтения файлов).
- `/Model` — чистые DTO-структуры данных (`Book`, `BookDirectory`, `Config`).

## 🚀 Использование

Утилита поддерживает несколько удобных команд для управления и проверки.

### 1. Синхронизация и обновление (Основная команда)
Сканирует указанную в настройках директорию, находит новые файлы, удаляет упоминания о несуществующих и обновляет JSON-файл плагина, выводя цветной отчет:
```bash
nin
```
*Также можно передать путь к папке вручную в качестве аргумента:* `nin <path>`

### 2. Аудит файлов на диске
Сканирует физическую папку на диске и показывает, сколько папок и потенциальных книг там находится в данный момент. **Ничего не записывает в JSON** (безопасный режим):
```bash
NIN check
```
*Или для конкретной папки:* `nin check /home/user/Downloads/`

### 3. Проверка текущей базы закладок
Выводит быструю статистику из файла конфигурации плагина, показывая, сколько папок и книг зарегистрировано в системе прямо сейчас:
```bash
NIN lib
```

### 4. Изменение конфигурации путей
Позволяет быстро перенастроить пути к рабочей папке, файлу JSON или программе для чтения:
```bash
# Изменить путь к папке с книгами
NIN set dir /home/user/Books/

# Изменить путь к JSON-файлу плагина Bookmarks
NIN set json /home/user/.config/noctalia/bookmarks.json

# Изменить программу открытия по умолчанию
NIN set prog zathura
```

## 🛠️ Сборка под Linux (Arch Linux)

Проект собирается в один самодостаточный исполняемый файл, которому не нужен установленный в системе .NET SDK:

```bash
dotnet publish -c Release -r linux-x64 --self-contained true /p:PublishSingleFile=true
```

Готовый бинарник будет находиться по пути `bin/Release/net10.0/linux-x64/publish/NIN`. Для удобства использования переместите его в ваш системный `$PATH` (например, в `~/.local/bin/`).
