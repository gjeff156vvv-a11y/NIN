# NIN# NIN

Консольная утилита (CLI) на .NET для автоматического сканирования книг и синхронизации локальной библиотеки с JSON-файлом закладок.

## Особенности

- **Два режима работы:** запуск без аргументов для синхронизации библиотеки или использование подкоманды `set` для настройки путей.
- **Оптимальный алгоритм фильтрации:** утилита проверяет уникальность книг по строке команды запуска (`Cmd`) с помощью LINQ (Query Syntax) до создания тяжелых объектов в памяти, исключая появление дубликатов.
- **Быстрый запуск:** написана на базе современной библиотеки `System.CommandLine 3.0` с синхронным жизненным циклом.

## Архитектура проекта

Код декомпозирован на логические блоки для простоты поддержки:
- `Program.cs` — точка входа, конфигурация команд и аргументов CLI.
- `ManagerConfig.cs` — контроллер настроек, чтение/запись конфигурации и валидация дубликатов на месте.
- `Book.cs` — чистая DTO-структура данных книги.
- `Config.cs` — модель конфигурации приложения.

## Использование

### Скан и синхронизация библиотеки
Запуск утилиты без аргументов сканирует указанную в настройках директорию на наличие PDF-файлов и заносит новые книги в JSON-базу закладок:
```bash
nin
```

### Изменение настроек
Для изменения путей к файлам используется подкоманда `set`:
```bash
# Изменить рабочую директорию с книгами
nin set dir /home/user/Documents/books/

# Изменить путь к JSON-файлу закладок
nin set json /home/user/.config/app/bookmarks.json
```
